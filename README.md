# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

页眉挂**拱顶历史峰值墙**：左列断面、右列该断面历史峰值与峰值时刻，带手动刷新（另每 2 秒自动刷新）和锁定按钮。峰值只从**办结集合**（status=done）按 `abs(收敛值)` 取最大；只有待判读数、尚未办结的断面显示“待办结”，**绝不虚填峰值**。

测量员可把某断面（或全部未锁断面）当前的峰值与峰值时刻**压成只读副本写进锁区**。锁定之后：

- 锁区副本定格，新办结的读数只会更新“实时（未锁）”列，**已锁列不再变**；
- 锁区专页允许测量员**手改数字/时刻**，改动直存锁区，**任何路径都不会回到办结集合重算**，也不被后续办结覆盖；
- 巡检岗对峰值墙、锁区只许观看，锁、改、提交一律 403。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/peaks` | 登录 | 峰值墙：每断面实时峰值/时刻、未办结不虚填（null）、已锁附冻结副本 |
| POST | `/api/peaks/lock` | 测量员 | body 可空（锁全部未锁办结断面）或 `{"chainage":"K12+180"}`；已锁断面跳过不重算，未办结断面进 `skipped` |
| GET | `/api/locks` | 登录 | 锁区只读副本列表 |
| PATCH | `/api/locks/<id>` | 测量员 | 手改 `peak_mm` 和/或 `peak_at`，直存、不触发重算 |
